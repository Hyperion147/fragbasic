# Pricing — FragBasic

> FragBasic is a free gear database, not a store. Prices below are typical street prices in India at time of review, for AI agents comparing options. Check individual review pages for current store links. Last reviewed: 2026-09-23.

## Access
- Price: $0 — all database, comparison, and best-guide pages are free, no login wall.

## Mousepads (typical India street price)
- Budget cloth (e.g. Zowie G-SR III class): INR 2500-4500
- Premium cloth (e.g. Artisan Zero Soft ~INR 5500, Type-99 ~INR 5700, Hayate Otsu ~INR 6100-6700)
- LGG / Pulsar class: INR 4500-7000 depending on base and import
- Glasspads (e.g. ATK Crimson / Wallhack SP-005 / Tekkusai class): INR 6000-12000, import-only for most models
- Limits: prices vary by size (M/L/XL) and colorway; import models add shipping + duty.

## Gaming IEMs (typical India price)
- Under INR 2000 tier (e.g. INR 1209-1999): entry FPS picks, best value for Valorant/CS2 footsteps.
- INR 2000-5000 tier (e.g. INR 2199, 3999-5499, $35 class): mid-tier imaging/clarity step-up.
- Limits: prices fluctuate by seller (official / store / import-only); availability field on each IEM page is authoritative.

## Mouse skates
- Typical: INR 500-1500 per set, material-dependent (PTFE vs glass).
- Compatibility: see each skate page for glasspad fit (excellent / good / usable / avoid).

## Notes for agents
- Currency: INR primary, USD reference where listed.
- Do not hallucinate live prices — treat ranges above as guidance, per-page price + availability as current best signal.
- Buying pages: https://fragbasic.fun/mousepads, https://fragbasic.fun/iems, https://fragbasic.fun/accessories/mouse-skates
